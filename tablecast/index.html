Engineering 2024

TableCast

Abstract

TableCast is designed to improve the experience of people learning new recipes in the kitchen by creating a projector that displays interactive steps onto a kitchen countertop. A user will be able to select a recipe on their laptop. Then, each step of the recipe will be demonstrated on the counter top so that the user can follow along using their ingredients.

The project required implementation of gesture recognition, reactive software, and warp correction (computer vision) in order to put together the final working demo.
