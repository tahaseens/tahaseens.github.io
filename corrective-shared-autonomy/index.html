Overview

Nudge is a ROS 2 Jazzy and C++ research platform for a differential-drive ground robot operating in urban search-and-rescue-inspired environments. It asks whether sparse Xbox-controller corrections can communicate disagreement about the robot’s motion, plan, goal, or control authority and how autonomy should respond without reducing every intervention to continuous teleoperation.

The project is simulation-first. Initial development uses Gazebo Harmonic with Nav2, AMCL, and RViz. Partially known environments are the intended research setting, extending beyond the current known-map navigation baseline.

What exists now
Implemented foundation

Repository scaffolding, package and interface boundaries, configuration contracts, state-machine primitives, robot description, logging structures, and a known-map autonomous simulation baseline.

Still to verify and build

Runtime verification of the navigation baseline, correction detection, semantic interpretation, authority arbitration, independent safety integration, and complete shared-autonomy behavior.

Research approach
Explicit condition

The operator supplies a semantic label with each correction, identifying disagreement about motion, plan, goal, or control authority.

Implicit condition

The system interprets the correction using deterministic heuristics and observable context rather than an operator-provided semantic label.

Both conditions are planned to use the same downstream assistance architecture so the interpretation method is the primary difference.
