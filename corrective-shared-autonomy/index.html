Overview

This project explores shared autonomy between a human operator and an autonomous robotic system, with an emphasis on using physical corrective input as more than direct teleoperation. The goal is to investigate how sparse human interventions can influence autonomous behavior while allowing the system to retain meaningful autonomy.

The system will run on an NVIDIA Jetson Orin Nano using ROS 2, with the core robotics and autonomy components implemented primarily in C++. Initial interaction will use physical controller input, such as an Xbox controller or mouse, to explore corrective control, human-autonomy disagreement, and dynamic allocation of control authority.

Current direction

The initial direction focuses on a robotic system capable of operating autonomously while accepting intermittent physical corrections from a human operator. Rather than treating every controller input as continuous manual control, the project will explore ways for those interventions to influence subsequent autonomous behavior.

Areas currently being investigated include corrective control, human-autonomy disagreement, adaptive control authority, and interpretation of intervention patterns at different levels of robot behavior.
